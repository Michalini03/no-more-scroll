! Title: no-more-scroll (Brave)
! Description: Hides Instagram Reels buttons and tabs, blocks the Reels feed page. No redirects, no swipe lock.
! Usage: Brave on iPhone -> Settings -> Shields & Privacy -> Content Filtering -> Add Custom Filters, paste this file.
! YouTube Shorts are not covered here: Brave has its own built-in Shorts blocker.
! Keep in sync with the selectors in scripts/instagram-no-reels.user.js

! Reels button (the search icon is left alone, it opens Explore + search)
instagram.com##a[href="/reels/"]
instagram.com##a[href="/reels"]
instagram.com##a[href^="/reels/?"]
instagram.com##a[href^="/reels?"]

! Reels tab on profiles (/<username>/reels/). Safari keeps this tab because its swipe lock stops
! each reel; Brave has no swipe lock, so the tab is hidden here. Delete this rule to keep it.
instagram.com##a[href$="/reels/"]
instagram.com##a[href$="/reels"]

! Block the Reels feed page when it is loaded directly (link or typed address).
! Only the bare feed: single reels (/reel/<id>, /reels/<id>) still open.
! Query prefixes have no end anchor, so tracking parameters are also covered.
|https://www.instagram.com/reels/|$document
|https://www.instagram.com/reels|$document
|https://www.instagram.com/reels/?$document
|https://www.instagram.com/reels?$document
|https://instagram.com/reels/|$document
|https://instagram.com/reels|$document
|https://instagram.com/reels/?$document
|https://instagram.com/reels?$document
